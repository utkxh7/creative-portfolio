## What it actually is
A minimal React + Vite single-page portfolio website with dynamic project routing (`/:projectId`), co-designed with Haoqi.

## Status
functional prototype

## Why I started it
Collaborating on a minimalist, highly focused portfolio layout featuring tailored project deep-dives.

## What I actually did
- Built React SPA using Vite, React Router (`BrowserRouter`, `Routes`, `Route`), and Oxlint (`src/App.jsx`).
- Created responsive grid homepage (`src/pages/Home.jsx`) and dynamic project details page (`src/pages/ProjectDetail.jsx`).
- Integrated `ScrollToTop` utility component to reset scroll position on route changes.

## What's real vs. what's conceptual
- **Real**: React routing structure, component architecture, CSS layout, project data binding, and local Vite dev build.
- **Conceptual**: Live public custom domain deployment and ongoing multi-client project hosting.

## What I'd say if someone asked a hard follow-up
If asked how this differs from `utkarsh-portfolio`: "This codebase is a collaborative minimalist variant focused on high-contrast grid layouts and clean project detail routes, whereas `utkarsh-portfolio` includes dossier modes and visual simulations."
